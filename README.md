📱 Aplicativo Android: Login com Menu Lateral e Cadastro
Este é um projeto de aplicativo Android simples com sistema de login, tela logada com menu lateral (Navigation Drawer) e uma funcionalidade inicial de cadastro de músicas. O projeto foi desenvolvido como parte da minha aprendizagem na pós-graduação em Inteligência Artificial para Engenharia de Teste de Software (IArtes) da Universidade Federal do Amazonas (UFAM).

🎯 Objetivo
Criar um app funcional em Android Studio que aplique:

Conceitos de navegação entre atividades

Interface com NavigationDrawer

Integração básica com Intent

Interface com ConstraintLayout

Componentes básicos da UI Android (TextView, Button, etc)

🛠️ Tecnologias e Ferramentas Utilizadas
Java (linguagem principal)

Android Studio

ConstraintLayout

NavigationView e DrawerLayout

Intents para navegação

Estrutura modular e boas práticas de organização de código

🚀 Funcionalidades Implementadas
Tela de Login com campos de entrada e botão “Entrar”

Validação de entrada do usuário

Navegação para a Tela Logada

Menu lateral com itens como: Home, Perfil, Configurações, Compartilhar, Sobre

Tela de Preferências personalizada que recebe e exibe o nome do usuário logado

Botão para simular o cadastro de uma nova música

📂 Estrutura de Telas
Tela de Login

Campos de usuário e senha

CheckBox para salvar login (futuro uso com SharedPreferences)

Botão para entrar

Tela Logada

Exibe nome do usuário

Menu lateral com opções de navegação

Ação para ir à tela de cadastro de música

Tela de Preferências

Exibe saudação personalizada com nome do usuário

Tela de Cadastro de Música (em desenvolvimento)

🧠 Relacionamento com o Curso IArtes/UFAM

Experimentar o uso de IA para geração de casos de teste
